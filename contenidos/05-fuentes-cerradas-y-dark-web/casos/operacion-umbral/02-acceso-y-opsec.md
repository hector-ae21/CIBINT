# Umbral · Plan de acceso y seguridad operacional

**Cuándo hacerlo:** después de la explicación de [preparación, Tor y seguridad operacional](../../README.md#acceso-seguro-y-búsqueda-de-credenciales-filtradas), antes de la búsqueda defensiva de exposición.

[Situación y materiales](README.md#situación) · [Definiciones](../../definiciones.md)

## Objeto de la práctica

Elegir el acceso mínimo que responde al encargo y explicar sus riesgos. El plan se prepara con las fichas y el [catálogo de herramientas](../../herramientas.md). No se instalan programas ni se abren las referencias ficticias.

## Alternativas propuestas

| Opción | Acción propuesta |
|---|---|
| P-01 | Analizar las exportaciones mínimas ya autorizadas de A y B |
| P-02 | Crear una cuenta personal en un foro para solicitar una muestra |
| P-03 | Pagar y abrir el archivo de UMB-F08 para verificar el anuncio |
| P-04 | Leer la documentación oficial de Tor y preparar una demostración limitada al servicio oficial de comprobación, si se autoriza |
| P-05 | Abrir un documento desconocido fuera del navegador porque se está utilizando una máquina virtual |
| P-06 | Solicitar al responsable interno un resumen sobre la sesión de A-04, sin pedir su token |

## Trabajo

1. Clasifica cada opción como permitida por el expediente, condicionada a autorización adicional o excluida. Justifica la respuesta con la pregunta que pretende resolver.
2. Prepara un plan que identifique entorno de trabajo, cuenta de acceso, datos que se conservarán, destinatarios y condición de parada.
3. Explica qué información puede conocer un proveedor sobre las consultas realizadas.
4. Distingue visitar una web convencional mediante Tor de acceder a un servicio onion. ¿Qué demostraría un resultado positivo del comprobador oficial y qué seguiría sin demostrar?
5. Explica por qué iniciar sesión con una cuenta personal o abrir un archivo externo puede cambiar el riesgo aunque se utilice Tor Browser.

## Resultado

Completa la sección de acceso del [registro de práctica](registro-practica.md). Debe quedar una decisión por opción y un plan suficiente para continuar con las muestras entregadas. Si no se realiza demostración de navegador, registra «análisis documental; sin navegación propia».
