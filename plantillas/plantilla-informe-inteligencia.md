# Plantilla — Informe de inteligencia

> Copiar esta plantilla como punto de partida para un informe. Sustituir cada sección; eliminar las que no apliquen.

## Título

*Frase breve que resuma el hallazgo principal.*

## Resumen ejecutivo

*3-5 líneas: qué se preguntó, qué se encontró, qué se recomienda. Debe poder leerse solo y ser suficiente para quien decide.*

## Requerimiento de inteligencia

*Qué pregunta original motivó este informe y quién la formuló.*

## Fuentes y método

*De dónde viene la información y cómo se obtuvo (sin detallar procedimientos sensibles si el informe va a circular ampliamente).*

## Análisis

*Interpretación de la evidencia: qué significa, qué patrones o conexiones se identifican.*

## Nivel de confianza

| Nivel | Criterio |
|---|---|
| Alto | Múltiples fuentes independientes y fiables, corroboradas |
| Medio | Una fuente fiable, o varias fuentes de fiabilidad media |
| Bajo | Fuente única, no verificada, o información contradictoria |

## Recomendación

*Qué acción se propone a partir de este análisis.*

## Anexos

*Evidencia de soporte (capturas, IOCs, referencias).*
