# Operación Prisma · Elección de herramientas

Esta parte se resuelve con el expediente y el [catálogo de herramientas](../../herramientas.md). Todavía no se instala, no se consulta Internet y no se ejecuta ninguna transformación.

## Elegir por la necesidad

Compras necesita valorar el cambio de canal. No todas las preguntas requieren una plataforma amplia. Una herramienta que conserve una página no responde por sí sola a quién controla el perfil; una herramienta de grafos no verifica automáticamente la fecha de una imagen.

## Ejemplo resuelto

| Pregunta | Opciones | Elección inicial | Motivo |
|---|---|---|---|
| ¿La imagen tuvo un uso anterior? | Maltego, Lens/TinEye, Hunchly | Búsqueda inversa, si hiciera falta obtener nueva evidencia | Busca coincidencias de imagen; el grafo y la captura tienen otra función |

En el expediente esa pregunta ya cuenta con PRI-F06 y PRI-S05. Por tanto, puede interpretarse antes de buscar. La herramienta se elige para una laguna real, no para repetir una comprobación ya disponible.

## Trabajo guiado

Para cada necesidad compara al menos dos opciones y descarta una con un motivo concreto:

| Pregunta | Evidencia ya disponible | Dato que falta | Dos herramientas candidatas | Mejor opción y motivo | Opción descartada y motivo |
|---|---|---|---|---|---|
| Relación entre perfil y proveedor | | | | | |
| Aviso de cambio en el canal conocido | | | | | |
| Dependencia de las tres publicaciones | | | | | |
| Conservación de un anuncio que puede desaparecer | | | | | |
| Seguimiento de menciones en varios idiomas durante semanas | | | | | |
| Referencia histórica de un dominio en un archivo especializado | | | | | |
| Distinguir dos sociedades con la misma denominación | | | | | |

Incluye Intelligence X y OpenCorporates en la comparación cuando respondan a esas preguntas. Explica por qué OpenSanctions no es necesario para autenticar el canal si el encargo no pide una comprobación de listas.

Utiliza estos criterios: adecuación a la pregunta, fuente, resultado, alcance, acceso y posibilidad de verificar. No hace falta puntuar con números si puedes explicar la comparación.

## Dos cambios del encargo

1. El responsable solo necesita revisar tres publicaciones ya entregadas. ¿Compensa Babel Street frente a una revisión manual? ¿Qué aporta Maltego?
2. El aviso aparece en varios países y hay que seguir nuevas menciones durante un mes. ¿Qué cambiaría en la elección? ¿Qué cobertura y acceso necesitarías confirmar?

Completa un plan de ejecución para la parte posterior:

| Herramienta elegida | Entrada exacta o clase de entrada | Fuente esperada | Resultado que resolvería la pregunta | Límite | Alternativa si no hay acceso |
|---|---|---|---|---|---|
| | | | | | |

## Comprobación

La mejor herramienta depende de la pregunta. Puede ser un buscador para localizar un aviso, Maltego para ordenar relaciones, Hunchly para conservar una publicación o Babel Street para un seguimiento multilingüe con acceso adecuado. La respuesta debe explicar por qué; no basta con enumerar marcas.

La elección queda preparada para [Obtención con herramientas](03-obtencion-con-herramientas.md).
