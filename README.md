# CIBINT — Ciberinteligencia

Documentación de referencia de la asignatura **Ciberinteligencia** (Experto Universitario en Ciberseguridad).

Este repositorio contiene el **material conceptual estable** de la asignatura: no cambia de un curso académico a otro. Las actividades, prácticas, retos y noticias de cada convocatoria viven en un repositorio propio por curso, que enlaza directamente a los contenidos de aquí.
