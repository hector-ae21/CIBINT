*Caso real: un SOC recibe un indicador de compromiso (IOC) y necesita saber si corresponde a un actor conocido y qué tácticas suele emplear, para anticipar los siguientes pasos del ataque.*

## Concepto clave

*Definir Threat Intelligence (estratégica/táctica/operativa/técnica), IOC vs TTP, y MITRE ATT&CK como marco de referencia para describir el comportamiento de un atacante.*
