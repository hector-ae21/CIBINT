**Cuándo hacerlo:** después de [Método de análisis y valoración](../../README.md#método-de-análisis-y-valoración) y [Casos documentados y práctica de contraste](../../README.md#casos-documentados-y-práctica-de-contraste).

[Situación y materiales](README.md#situación) · [Definiciones](../../definiciones.md)

## Objeto de la práctica

Responder al encargo con una valoración que pueda revisarse. Se utiliza el expediente completo y el [registro de práctica](registro-practica.md), no fuentes nuevas sobre Nácar.

## Contraste documental

Resuelve la comparación de [Genesis Market y Collection #1](../casos-reales.md). Esas fuentes sirven para interpretar categorías y unidades, no para acreditar que Nácar esté afectada.

## Explicaciones alternativas

Compara al menos estas posibilidades, sin decidir por el título de la publicación:

| Explicación | Evidencia a favor | Evidencia que la limita | Dato necesario para distinguirla |
|---|---|---|---|
| Se presenta como actual una colección que contiene datos históricos | | | |
| La alerta mezcla referencias antiguas con categorías que requieren revisión actual | | | |
| Todo el volumen anunciado corresponde a cuentas vigentes y secretos utilizables | | | |

No es necesario dar el mismo peso a las tres. Debe explicarse qué respaldo tienen y por qué una prioridad de respuesta puede mantenerse aunque no se confirme una hipótesis completa.

## Nota para los destinatarios

Redacta una nota de **hasta 350 palabras** que incluya:

1. Decisión que se necesita tomar y alcance de la revisión.
2. Hallazgos principales con referencias UMB y unidades de recuento claras.
3. Diferencia entre información histórica, categorías declaradas y acceso documentado pendiente de contraste.
4. Confianza de las valoraciones y limitación que impide confirmar el volumen o la actualidad anunciados.
5. Tres prioridades con responsable propuesto y dato necesario para su cierre.

## Defensa del razonamiento

Debe poder explicarse qué cambiaría la conclusión si la cuenta A-04 resultara legítima, si el inventario fuera incompleto o si un proveedor demostrara un origen independiente. También debe justificarse qué acciones seguirían excluidas aunque la alerta fuera más creíble.

La entrega del ejercicio, si se solicita, seguirá el canal y las condiciones del curso. No se publica ningún dato ajeno al expediente ni se crea una actividad evaluable por iniciativa propia.
